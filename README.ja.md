ProductTally は、クリエイターや小規模チーム向けの独立した製品情報サイトです。SaaS、ソフトウェア、デジタル製品を探せます。製品チームは、どんな場面で自社製品が役立つのかを、利用を検討している人に伝えられます。

## サイトを見る

- [製品ディレクトリ](https://producttally.com/ja/products/) — 検索やカテゴリで製品を絞り込み、詳細ページで用途、機能、料金を確認できます。
- [ガイド一覧](https://producttally.com/ja/guides/) — テーマや製品ごとに、選び方や使い始め方を解説する記事を探せます。

## ご提案・レビューのご依頼

- **製品のご提案や情報の訂正。** 製品の URL と、想定する利用者や訂正したい箇所を Evan までメールでお知らせください。
- **製品レビューのご依頼。** **1 製品につき 99 米ドルの一括払い**で、製品の調査、詳細ページ、実践ガイド 1 本をサイトの 4 言語で提供します。製品の URL と取り上げてほしい利用場面をお送りください。Evan が内容を確認し、PayPal の支払いリンクをメールでお送りします。依頼を受けたレビューにはその旨を明記し、結論は ProductTally が独自に判断します。
