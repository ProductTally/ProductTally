ProductTally 是面向创作者和小团队的独立产品指南。你可以在这里发现适合自己的 SaaS、软件和数字产品，也可以让潜在用户了解你的产品能解决什么问题、如何上手。

## 浏览网站

- [产品广场](https://producttally.com/zh/products/) · 按分类筛选或搜索产品，在详情页查看适用场景、功能和定价。
- [指南库](https://producttally.com/zh/guides/) · 按主题或产品浏览实用文章，了解如何选型并搭建自己的工作流程。

## 合作方式

- **推荐产品或提交勘误。** 给 Evan 发邮件，附上产品网址，并简要说明产品适合谁，或哪处信息需要更新。
- **委托产品评测。** 每款产品一次性收费 **99 美元**，包含产品调研、产品详情页和一篇实用指南，内容提供四种语言版本。请通过邮件发送产品网址和希望覆盖的使用场景。Evan 确认范围后会通过邮件发送 PayPal 付款链接。ProductTally 会标明委托评测，并独立决定评测结论。
